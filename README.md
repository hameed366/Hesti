# حصتي

عرض الدروس وإدارة الحصة: كتاب الرياضيات للصفوف السادس إلى التاسع، قرعة الطلاب، مؤقّت، ساعة الحصة، السبورة.
المشروع يعمل **كموقع ويب (PWA)** و**تطبيق أندرويد** و**تطبيق آيفون** من نفس الكود.

## الملفات

| المسار | الوظيفة |
|---|---|
| `index.html` `curriculum.json` `img/` | التطبيق والمنهج وصور الكتاب |
| `manifest.webmanifest` `sw.js` `icons/` | تثبيت التطبيق والعمل بدون إنترنت (ويب) |
| `scripts/build.mjs` | يجهّز مجلد `www` (ومعه `--vendor` ينزّل الخطوط ومكتبات PDF/Excel ليعمل التطبيق بلا إنترنت) |
| `capacitor.config.json` `package.json` `assets/` | غلاف أندرويد وآيفون (Capacitor 8) والأيقونات |
| `.github/workflows/` | نشر الويب وبناء APK وبناء آيفون تلقائياً |

## 1) الرفع إلى GitHub

```bash
git clone https://github.com/hameed366/Hesti.git
cd Hesti
# انسخ كل محتويات هذا المجلد إلى هنا (استبدل الموجود، وانتبه للمجلدات المخفية .github)
git add .
git commit -m "حصتي: PWA + أندرويد + آيفون"
git push origin main
```

## 2) نسخة الويب (GitHub Pages)

1. في المستودع: **Settings ← Pages ← Source: GitHub Actions**.
2. بعد أول دفع ينشر `pages.yml` الموقع تلقائياً على: `https://hameed366.github.io/Hesti/`
3. **آيفون:** افتح الرابط في Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**. مجاني ويعمل بملء الشاشة.
   **أندرويد:** افتح الرابط في Chrome ← **تثبيت التطبيق**.

بعد أول فتح للدرس يُحفظ في الجهاز ويعمل بدون إنترنت.

## 3) تطبيق أندرويد (APK)

1. في المستودع: **Actions ← بناء تطبيق أندرويد (APK) ← Run workflow**.
2. بعد دقائق نزّل الملف `hessati-android-apk` من أسفل صفحة التشغيل، وفك ضغطه.
3. انقل `app-debug.apk` إلى الجوال وثبّته (يلزم السماح بالتثبيت من مصدر غير معروف).

للنشر في Google Play تحتاج نسخة موقّعة (release) ومفتاح توقيع خاص بك.

## 4) تطبيق آيفون

- أسهل طريقة مجانية: إضافة الموقع إلى الشاشة الرئيسية (الفقرة 2).
- تطبيق أصلي على آيفون حقيقي أو TestFlight يحتاج **جهاز Mac وXcode 26 وحساب Apple Developer**:

```bash
npm install
npm run ios:add
npx cap open ios      # من Xcode: اختر الفريق (Team) ثم Run
```

- `ios.yml` في Actions يتحقق فقط أن المشروع يُترجم ويُنتج نسخة للمحاكي (بدون توقيع).

## ملاحظات مهمة

- **البيانات محفوظة في كل جهاز على حدة** (صفوف الطلاب، الدرجات، الكتب المستوردة). نسخة الموقع ونسخة التطبيق لا تتشاركان البيانات، فاستخدم **النسخ الاحتياطي** من الإعدادات للنقل بينها.
- التصدير (نسخة احتياطية، Excel) يُنزَّل كملف في الويب، ويفتح نافذة المشاركة في التطبيق لتحفظه في «الملفات».
- ميزة **«ربط الجوال»** تعمل فقط داخل Claude، وهي مخفية في هذه النسخ.
- لتحديث الموقع: عدّل الملفات وادفع، وارفع رقم `VER` في `sw.js` إذا غيّرت المنهج أو الصور.
- لتغيير معرّف التطبيق (`com.hameed.hessati`) أو اسمه عدّل `capacitor.config.json` قبل أول بناء.
- ملاحظة: جُرّبت نسخة الويب (التثبيت، العمل بلا إنترنت، التنزيل). أما بناء أندرويد وآيفون فلم يمكن تشغيله من بيئتي، فإن فشل أي workflow أرسل سجل الخطأ.
